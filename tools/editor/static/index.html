The Pebble SDK

        
Authoring, previewing, validating and budgeting all work with
        nothing installed. Producing a .pbw needs the Pebble SDK — about
        767 MB, and it carries its own ARM toolchain, so it is one install rather
        than two.

        
The editor does not ship the SDK and does not download it
        directly. Pebble licenses it to you, and the terms are explicit that
        the licence is non-transferable and that the SDK may not be redistributed. So this
        button drives Pebble’s own pebble tool: the files go from
        Pebble to your machine, exactly as if you had run it yourself.

Emulator

        
Builds this project for one platform and installs it into
          pebble's own emulator, baked for whichever orientation this
          project is currently set to (see Settings) -- the same asset build the Build
          button runs, so what you see here is what the resource budget is measured
          against, not a separate copy of it.

        

          
          
          
        

        
        A build knob, not a project setting -- pnx_config.h's own
          screen-lock, engaged from startup instead of waiting for game code to call
          it. Off the wrist there is no ambient light and no wrist to glance at, so a
          real timeout just looks like a hang; this is saved into the manifest (so it
          survives a reload) but only ever reaches a build through THIS panel's own
          pebble build call, never a shipped one. Takes effect on the next
          Build & run / Rebuild.

Real device

        
Builds this project (the same asset build Build/Package use)
          and installs it straight onto a watch. Turn on the phone app's own Developer
          Connection first (its Settings), then set its address on the Project Settings
          tab.

        Press and hold, on screen or with ↑/↓/Enter/Backspace while this
          panel has focus -- a real hold, not a canned click, so pnx_input_held_ms
